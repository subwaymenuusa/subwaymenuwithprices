MENU HELP

Questions before your next order.

What does this menu page cover?

This edition brings together six sandwich examples and separate price tables for wraps, protein bowls, salads and catering. Use the overview to jump between formats.

Are the pictured sandwich prices for a Footlong?

No. The product cards and sandwich comparison use reference 6-inch prices. Each other table lists its own format.

Why do similar fillings have different prices?

Format, portion and recipe can change between a sandwich, wrap, salad and bowl. Compare the complete item description rather than the filling name alone.

Do these prices include drinks?

The listed food prices do not imply an included drink. Check the contents of your selected item or package before adding beverages.

How should I use the calorie values?

Read them as reference values for the listed sandwich recipes. Custom ingredients and different portions may change the total.

Can I order catering for a small group?

Review individual boxed meals as well as shared platters. Confirm minimum quantities and availability with the restaurant handling the order.

Does this website accept orders?

This is a menu browsing guide. It does not process restaurant orders or payments.
